# 情報セキュリティ評価報告書(2026年度上期)

発行: 情報セキュリティ推進室
対象: 株式会社サンプル製作所 および国内グループ会社 6 社
評価期間: 2026年4月1日 〜 2026年6月30日
分類: 社外秘

## 1. エグゼクティブサマリ

本評価では、全社共通基盤および事業部門が個別に導入したシステムを対象に、
外部からの侵入経路、内部不正の可能性、委託先管理の 3 観点で点検を実施した。
重大な指摘が 4 件、中程度が 11 件、軽微が 23 件検出された。
前年度からの継続指摘が 7 件残っており、うち 3 件は 2 年連続の指摘である。

特に、事業部門が調達した SaaS のうち 14 サービスが情報システム部門の
把握外にあり(いわゆるシャドー IT)、うち 3 サービスで顧客の個人情報が
取り扱われていることが判明した。これらは全社の ID 基盤と連携しておらず、
退職者のアカウントが有効なまま残存しているものが 2 件あった。

## 3. 重大な指摘事項

### 3.1 特権 ID の棚卸しが 18 か月間未実施

基幹系 4 システムの特権 ID について、直近の棚卸し記録が 2024年12月であり、
規程で定める年 1 回の実施要件を満たしていない。
現在有効な特権 ID 47 件のうち、11 件は既に異動・退職した要員に紐づいていた。
うち 2 件は過去 90 日以内にログイン記録があり、誰が使用したか特定できない。

責任部門: IT 基盤部
是正期限: 2026年10月31日
是正責任者: 未定

### 3.2 受注ポータルの認証情報が平文で保存

社外からアクセスする受注ポータルにおいて、取引先の認証情報が
アプリケーションサーバ上の設定ファイルに平文で保存されていた。
当該ファイルはアプリケーション実行ユーザから読み取り可能であり、
Web アプリケーションの脆弱性を経由して外部から取得される可能性がある。

影響範囲: 取引先 1,240 社の管理者アカウント
責任部門: 販売システム部
是正期限: 2026年9月15日
是正責任者: 山田(販売システム部)

### 3.3 委託先における再委託の未把握

システム開発を委託している 12 社のうち、4 社が事前承認なく再委託を行っていた。
再委託先 7 社について、当社のセキュリティ基準への適合状況が確認できていない。
うち 1 社は国外に開発拠点を有し、当社の設計情報および一部の本番データを
国外で取り扱っていた可能性がある。

責任部門: 調達部、法務部
是正期限: 2026年12月31日
是正責任者: 未定

### 3.4 インシデント対応の責任分界が未定義

クラウド移行済みの 9 システムについて、インシデント発生時の
一次対応・原因調査・顧客通知の責任分界がクラウド事業者との間で
文書化されていない。2026年5月に発生した障害では、原因調査の開始まで
26 時間を要し、その大半が責任範囲の確認に費やされた。

責任部門: IT 基盤部、法務部
是正期限: 2026年11月30日
是正責任者: 伊藤(IT 基盤部)

## 4. 中程度の指摘(抜粋)

- ログの保管期間が規程の 1 年に対し、実際は 90 日のシステムが 12 件ある
- 多要素認証が VPN のみで、SaaS 側では未適用のものが 31 サービス
- 開発環境に本番データの複製が残存(7 環境、最古は 2023 年)
- 脆弱性診断が年 1 回のみで、リリース時の診断が定義されていない
- バックアップからの復旧試験が 3 年間未実施
- 退職者アカウントの停止が手作業で、平均 11 日を要している

## 6. 是正計画と課題

是正に必要な工数は概算で 4,200 人日、費用は約 3.8 億円と試算される。
ただし、2026年度予算は既に確定しており、追加予算の確保には
2027年度の予算編成を待つ必要がある。
情報セキュリティ推進室の専任要員は現在 3 名で、全社 51 サービス・
38 システムの継続的な監視は現体制では困難である。

## 7. 残存リスクの受容について

上記のうち、2026年度中に是正が完了しないものについては、
情報セキュリティ委員会にて残存リスクの受容可否を審議する。
現時点で受容が想定されるのは以下。

- シャドー IT の全数把握(是正は 2027年度以降)
- 開発環境の本番データ削除(業務影響の調査が必要)

受容者: 情報セキュリティ委員会
